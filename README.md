Начните с серверов с низкой реальной задержкой и попробуйте несколько лучших результатов.

# 🧪 Как правильно проверять VPN-конфиги

## TCP ping ≠ рабочий VPN

Сервер может отвечать на сетевой порт и всё равно плохо работать как VPN.

Поэтому при выборе используйте **реальный тест подключения**, если он поддерживается клиентом.

### Рекомендуемый алгоритм

1. Обновите подписку.
2. Запустите Real Delay / Реальную задержку.
3. Отсортируйте рабочие узлы.
4. Попробуйте несколько серверов.
5. Оцените не только задержку, но и фактическую скорость / стабильность.
6. Оставьте несколько запасных конфигураций.

### Почему стоит оставить несколько серверов

Даже хороший публичный сервер не является гарантированно постоянным.

Сегодня может работать один узел, завтра — другой.

Поэтому лучше иметь:

- 2–3 запасных сервера;
- саму подписку;
- локальную копию важных ссылок;
- доступ к этому репозиторию через сохранённую страницу или Fork.

# 🔄 Автоматические обновления

Репозиторий автоматически собирает и обновляет публичные конфигурации.

Текущий заявленный интервал обновления:

**каждые 6 часов.**

Во время обновления выполняются задачи:

1. сбор конфигураций из открытых источников;
2. удаление дубликатов;
3. проверка доступности;
4. формирование актуальных списков;
5. публикация обновлённых файлов.

### Важное ограничение

`verified_configs.txt` отражает состояние серверов **на момент проверки**.

Он не означает, что каждый сервер будет работать:

- у каждого оператора;
- в каждом городе;
- на каждом устройстве;
- в течение следующих суток;
- с одинаковой скоростью.

Поэтому автоматическое обновление и несколько запасных конфигураций — нормальная часть работы с публичными VPN.

# 📲 Настройте автообновление подписки

После первой настройки подписки желательно включить автоматическое обновление внутри самого VPN-клиента.

Практический подход:

- обновлять подписку несколько раз в день;

Так у вас будет свежий список без необходимости каждый раз заново копировать конфиги вручную.

# 🧩 Протоколы

В публичном пуле встречаются:

### VLESS

Современный протокол семейства Xray. Часто встречается в конфигурациях с Reality.

### Reality

Механизм, используемый в современных конфигурациях Xray для маскировки соединения под допустимый TLS-трафик.

### Hysteria2

Современный UDP-ориентированный протокол. В отдельных сетях может показывать хорошие результаты по скорости.

### Trojan

Протокол, который использует TLS-подобную модель соединения.

### VMess

Один из старых и широко распространённых протоколов экосистемы V2Ray.

### Shadowsocks

Лёгкий прокси-протокол, который остаётся широко поддерживаемым.

### TUIC

Современный протокол на базе QUIC.

> Не существует одного протокола, который будет лучшим абсолютно для всех пользователей. Проверяйте конкретные серверы и сочетание «протокол + клиент + сеть».

# ❓ FAQ

<details>
<summary><strong>Это действительно бесплатный VPN?</strong></summary>

Да. Конфигурации в публичных файлах доступны бесплатно.

При этом бесплатный публичный сервер не является гарантированно стабильным и может перестать работать.
</details>

<details>
<summary><strong>Какой файл использовать первым?</strong></summary>

Начните с:

```text
verified_configs.txt
```

Это рекомендуемый вариант для большинства пользователей.
</details>

<details>
<summary><strong>Почему verified-конфиг не работает у меня?</strong></summary>

Проверка отражает состояние конфигурации на момент проверки.

Доступность может различаться в зависимости от оператора, региона, клиента и времени подключения.

Попробуйте несколько серверов и обновите подписку.
</details>

<details>
<summary><strong>Почему TCP ping показывает сервер, а VPN не работает?</strong></summary>

TCP ping проверяет сетевую доступность порта.

Для VPN важна возможность фактического соединения. Используйте Real Delay / Реальную задержку, если это поддерживается вашим клиентом.
</details>

<details>
<summary><strong>Почему вчера всё работало, а сегодня нет?</strong></summary>

Публичные серверы меняются. Узел мог быть перегружен, отключён или перестать отвечать.

Обновите подписку и попробуйте другие конфигурации.
</details>

<details>
<summary><strong>Какой клиент лучше выбрать?</strong></summary>

Для Android доступны v2rayNG, Karing и NekoBox.

Для Windows — v2rayN и Karing.

Для iPhone / iPad — Karing, Streisand и v2Box.

Выбирайте приложение, которое удобнее именно для вашего устройства, и при проблемах попробуйте альтернативный клиент.
</details>

<details>
<summary><strong>Нужно ли обновлять подписку вручную?</strong></summary>

Желательно включить автоматическое обновление в самом VPN-клиенте.

При проблемах с подключением выполните принудительное обновление.
</details>

<details>
<summary><strong>Можно ли использовать несколько устройств?</strong></summary>

Это зависит от конкретной конфигурации, сервера и клиента.

Для публичных конфигов нельзя гарантировать одинаковое качество на нескольких устройствах одновременно.
</details>

<details>
<summary><strong>Безопасно ли использовать публичные VPN-конфиги?</strong></summary>

Публичный VPN-сервер принадлежит неизвестному оператору, поэтому не стоит считать его полностью доверенной средой.

Не передавайте через непроверенные публичные серверы банковские данные, критические пароли и другую чувствительную информацию.
</details>

<details>
<summary><strong>Нужен стабильный VPN без постоянного перебора серверов</strong></summary>

Публичный пул создан для бесплатного доступа и тестирования.
