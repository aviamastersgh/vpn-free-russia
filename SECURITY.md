# Security Policy

## Reporting security issues

Please do not publish private credentials, access tokens, passwords, private keys or other sensitive information in public issues.

For security-sensitive problems, use GitHub's private vulnerability reporting when available.

## Public VPN configurations

This repository contains publicly available VPN configuration data.

Do not submit:

- passwords;
- private keys;
- authentication tokens;
- personal information;
- payment information;
- credentials belonging to other people.

## Server infrastructure

The automated collection and verification infrastructure is intentionally maintained separately from the public repository.
