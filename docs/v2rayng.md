# v2rayNG Setup Guide

## Subscription

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

## Setup

1. Open v2rayNG.
2. Open Subscription Groups.
3. Add a new subscription.
4. Paste the URL.
5. Save.
6. Update subscriptions.
7. Run Real Delay.
8. Select a working server.
9. Connect.

## Important

TCP availability does not guarantee that a VPN tunnel will work correctly.

Always test the actual connection.

If all public configurations fail, see [Troubleshooting](troubleshooting.md).
