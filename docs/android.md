# Free VPN for Android

This guide explains how to use the public VPN subscription with Android clients based on Xray or sing-box.

## Subscription

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

## v2rayNG

1. Install v2rayNG.
2. Open Subscription Groups.
3. Add a subscription URL.
4. Paste the URL above.
5. Save the subscription.
6. Update the subscription.
7. Test real latency.
8. Select a working server.
9. Connect.

## Hiddify

1. Open Hiddify.
2. Add a profile.
3. Choose URL import.
4. Paste the subscription URL.
5. Update the profile.
6. Test several servers.

## NekoBox

1. Open Profiles.
2. Add a profile by URL.
3. Paste the subscription.
4. Update the profile.
5. Test several servers.

## Karing

1. Add a subscription.
2. Select URL import.
3. Paste the subscription URL.
4. Update.
5. Test the available servers.
