# VPN Troubleshooting

## One server does not connect

This is normal for public VPN configurations.

Try another server and refresh the subscription.

## The entire subscription fails

Try:

1. Update the subscription.
2. Test several servers.
3. Try another client.
4. Try the RU-specific list.
5. Check whether the network can access the subscription URL.

## VPN works on Wi-Fi but not mobile data

Mobile networks can have different filtering and routing.

Try:

- refreshing the subscription;
- testing different servers;
- using the RU configuration list;
- trying another compatible client.

## v2rayNG says connection failed

Check:

- subscription update;
- selected server;
- real latency;
- DNS;
- routing;
- whether other servers work.

## Hiddify does not connect

Refresh the profile and test several servers.

## Free VPN keeps stopping

Public servers are shared resources. They can become overloaded, blocked or disappear.

If you need a connection that does not require constantly searching for replacements, see [Stable VPN](stable-vpn.md).

## Important

No public VPN configuration can be guaranteed to work for every user, ISP, region or device.
