# Free VPN for Windows

The repository provides public configurations compatible with clients based on Xray and sing-box.

## Subscription URL

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

## Basic procedure

1. Install a compatible client.
2. Open subscription management.
3. Add the URL.
4. Update the subscription.
5. Test several servers.
6. Connect.

## If the subscription does not update

Try:

- opening the raw URL in a browser;
- using a CDN/raw mirror if available;
- refreshing the client;
- testing another client;
- checking whether the current network can access GitHub raw content.

See [Troubleshooting](troubleshooting.md).
