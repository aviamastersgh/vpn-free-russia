# VPN Free Russia FAQ

## Is this VPN free?

The repository provides public VPN configurations that can be used without paying for the configurations themselves.

## Are the configurations guaranteed to work?

No. Public VPN servers can become unavailable, overloaded or blocked.

## What should I use first?

Start with `verified_configs.txt`.

## What is the difference between verified and all configurations?

`verified_configs.txt` contains configurations selected after automated checks.

`all_configs.txt` contains the larger collected pool.

## What is VLESS?

VLESS is a lightweight proxy protocol commonly used with Xray-compatible clients.

## What is Reality?

Reality is a transport/security mechanism used by Xray configurations and commonly paired with VLESS.

## Why does a verified server still fail for me?

Automated checks cannot reproduce every real-world network condition. A server can be reachable during verification and fail later or from a particular ISP.

## Why does free VPN stop working?

Public servers can be overloaded, blocked, reconfigured or shut down.
