## Setup

1. Open Karing.
2. Add a subscription.
3. Select URL import.
4. Paste the subscription URL.
5. Save.
6. Update.
7. Test the available servers.
8. Connect.

For connection problems, see [Troubleshooting](troubleshooting.md).
