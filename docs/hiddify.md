## Subscription

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

## Setup

1. Open Hiddify.
2. Add a new profile.
3. Choose URL import.
4. Paste the subscription URL.
5. Update the profile.
6. Test several servers.
7. Connect.

If the connection repeatedly fails, see [Troubleshooting](troubleshooting.md).

If you prefer not to repeatedly replace public servers, see [Stable VPN](stable-vpn.md).
