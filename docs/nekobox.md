## Setup

1. Open NekoBox.
2. Open Profiles.
3. Add a profile.
4. Choose URL import.
5. Paste the subscription.
6. Update.
7. Test multiple servers.
8. Connect.

Public servers can disappear or become overloaded. If necessary, repeat the update and test another server.
