# Free VPN for iPhone and iPad

Use a compatible Xray / sing-box client that supports subscription URLs.

## Subscription

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

## Basic setup

1. Install a compatible VPN client.
2. Open profile or subscription management.
3. Choose URL import.
4. Paste the subscription URL.
5. Update the subscription.
6. Test several servers.
7. Connect to a working server.

## Mobile networks

A configuration that works on Wi-Fi may fail on mobile data.

Try:

1. Refreshing the subscription.
2. Testing multiple servers.
3. Trying the RU-specific configuration list.
4. Trying another compatible client.
5. Checking DNS and routing settings.

See [Troubleshooting](troubleshooting.md).

For users who need a more predictable connection, see [Stable VPN](stable-vpn.md).
