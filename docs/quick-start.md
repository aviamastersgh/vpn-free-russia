# Quick Start

## 1. Скопируйте подписку

```text
https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt
```

## 2. Добавьте её в клиент

Найдите в приложении раздел Subscription / Подписка / Добавить из URL и вставьте ссылку выше.

## 3. Проверьте сервер

Используйте Real Delay / Реальную задержку, если такая функция есть. Если первый сервер не работает — попробуйте следующий.

## 4. Если не подключается

Попробуйте обновить подписку, другой сервер, `all_configs.txt` или `ru_configs.txt`.

## Важно

`verified_configs.txt` означает только TCP-доступность host:port на момент проверки. Это не гарантирует успешный VPN-handshake, скорость, стабильность или работу в вашем регионе.
