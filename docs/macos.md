# Free VPN for macOS

Use a compatible Xray / sing-box client that supports subscription URLs.

## Subscription

`https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt`

Add the URL to your client's subscription manager, update the profile and test several servers.

If the public configurations are unreliable for your network, see [Stable VPN](stable-vpn.md).
