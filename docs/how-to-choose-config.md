# Как выбрать рабочий конфиг

В репозитории много публичных конфигураций. Не нужно перебирать их все вручную.

## С чего начать

Рекомендуемый порядок:

1. Сначала используйте `verified_configs.txt`.
2. Обновите подписку в VPN-клиенте.
3. Если первый сервер не подключается, попробуйте другой.
4. Если подходящего сервера нет, попробуйте `all_configs.txt`.
5. Для российских сетей также можно проверить `ru_configs.txt`.

Если клиент умеет измерять задержку, используйте эту функцию и выбирайте сервер с небольшой задержкой.

## Что означает verified

`verified_configs.txt` содержит конфигурации, которые во время последнего обновления прошли TCP-проверку адреса и порта сервера.

Это означает только, что:

- сервер принимал TCP-соединение;
- адрес и порт были доступны в момент проверки.

Это НЕ означает, что были полностью проверены:

- TLS;
- Reality;
- VLESS handshake;
- VMess handshake;
- Shadowsocks handshake;
- скорость;
- стабильность;
- доступность из конкретной сети или региона.

Поэтому даже конфигурация из `verified_configs.txt` может не подключиться у вас.

## Если конфиг не работает

Попробуйте:

1. обновить подписку;
2. выбрать другой сервер;
3. проверить задержку;
4. сменить транспорт или конфигурацию;
5. попробовать `all_configs.txt`;
6. попробовать `ru_configs.txt`.

Публичные серверы могут переставать работать в любое время.

## Какой файл использовать

| Файл | Для чего |
|---|---|
| `verified_configs.txt` | Первый вариант для обычного пользователя |
| `all_configs.txt` | Полный набор найденных конфигураций |
| `ru_configs.txt` | Список конфигураций/адресов для российских сетевых условий |

## Главное

Не ориентируйтесь только на страну сервера, название или красивое описание.

Лучший критерий — фактическое подключение и стабильность именно в вашем клиенте и вашей сети.
