# Рабочие VPN-конфиги

Репозиторий автоматически собирает публичные конфигурации и проверяет доступность серверов.

## Какой список использовать

- verified_configs.txt — рекомендуемый список для начала.
- all_configs.txt — полный набор найденных конфигураций.
- ru_configs.txt — дополнительный список для российских сетевых условий.

## Важно

verified означает только TCP-доступность host:port.

Это не гарантирует успешный TLS, Reality, VLESS, VMess или другой протокольный handshake.
