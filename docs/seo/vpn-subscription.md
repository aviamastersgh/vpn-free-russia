# VPN Subscription

VPN-подписка позволяет добавить список конфигураций в клиент по одному URL.

Рекомендуемый список:

https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt

Добавьте URL в разделе Subscription или Подписка вашего VPN-клиента.

Если серверы перестали работать, обновите подписку.
