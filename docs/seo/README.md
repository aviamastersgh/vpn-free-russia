# Free VPN Russia — VPN конфигурации для России

Бесплатные публичные VPN-конфигурации для совместимых клиентов.

В репозитории доступны VLESS, Reality, VMess, Trojan, Shadowsocks, Hysteria2 и другие конфигурации.

## Быстрый старт

Скопируйте подписку:

https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt

Затем добавьте URL в VPN-клиент и обновите подписку.

Полная инструкция: [Quick Start](../quick-start.md).

## Основные списки

- [verified_configs.txt](../../verified_configs.txt) — конфигурации, прошедшие TCP-проверку.
- [all_configs.txt](../../all_configs.txt) — полный найденный набор конфигураций.
- [ru_configs.txt](../../ru_configs.txt) — отдельный список для российских сетевых условий.

## Важно

`verified` означает только TCP-доступность `host:port` во время последней проверки.

Это не является полноценным тестом VPN-протокола и не гарантирует успешное подключение, скорость или стабильность.
