# Contributing

Спасибо за интерес к **VPN Free Russia**. Приветствуются улучшения документации, автоматизации, проверки конфигураций и структуры проекта.

## Документация

Приветствуются:

* исправления инструкций;
* улучшение навигации;
* исправление битых ссылок;
* переводы;
* точные технические уточнения;
* улучшение README и документации по VPN-клиентам;
* предложения по улучшению структуры репозитория.

## Generated data

Файлы:

* `all_configs.txt`
* `verified_configs.txt`
* `ru_configs.txt`

являются **генерируемыми данными** и автоматически обновляются GitHub Actions.

Не редактируйте эти файлы вручную без необходимости. Изменения могут быть перезаписаны следующим автоматическим обновлением.

## VPN configurations

При добавлении или изменении VPN-конфигураций:

* не публикуйте приватные ключи;
* не добавляйте пароли, токены или другие секретные данные;
* не публикуйте персональные данные;
* не представляйте временную TCP-проверку как гарантию работоспособности VPN;
* учитывайте, что публичные конфигурации могут перестать работать в любой момент.

## Accuracy

Проверка доступности `host:port` показывает только возможность установить TCP-соединение с указанным адресом.

Она **не гарантирует**:

* работоспособность конкретного VPN-протокола;
* стабильность соединения;
* высокую скорость;
* отсутствие блокировок;
* безопасность или конфиденциальность трафика.

## Pull requests

Перед отправкой Pull Request:

1. Проверьте изменения.
2. Убедитесь, что ссылки работают.
3. Не добавляйте секреты или персональные данные.
4. Не изменяйте автоматически генерируемые файлы без необходимости.
5. Кратко опишите, что было изменено и зачем.

## Issues

Если вы нашли проблему, укажите:

* что именно не работает;
* какой файл или раздел затронут;
* ожидаемое и фактическое поведение;
* дополнительные технические сведения, если они помогают воспроизвести проблему.

Не публикуйте в Issues приватные ключи, токены, пароли или другие секретные данные.

## Security

Уязвимости и проблемы безопасности следует описывать в соответствии с правилами, указанными в `SECURITY.md`.
