# 📱 客户端详细教程

## Android — v2rayNG

[v2rayNG Releases](https://github.com/2dust/v2rayNG/releases)

1. 安装 v2rayNG。
2. 打开 **订阅分组 / Subscription Group**。
3. 点击 **+**。
4. 粘贴 `verified_configs.txt` URL。
5. 保存分组。
6. 更新订阅。
7. 运行 **Real Delay / 真实延迟**。
8. 选择工作服务器。
9. 启动 VPN。

如果无法连接：更新订阅、换服务器、尝试 `ru_configs.txt`，或者换客户端。

# 🧪 如何测试 VPN 配置

## TCP Ping 不等于 VPN 正常

服务器端口可以响应，但实际 VPN 连接仍可能失败或速度很差。

优先使用：

**Real Delay / Real Latency / 真实延迟**

建议：

1. 更新订阅；
2. 运行真实测试；
3. 按延迟排序；
4. 测试多个节点；
5. 观察实际稳定性和速度；
6. 保留几个备用服务器。
